# La Sien Website Redesign Concept

A static, Vercel-ready redesign concept for La Sien Bottling Company.

## Stack
- HTML
- CSS
- Vanilla JavaScript

## Files
- `index.html` — page structure/content
- `style.css` — responsive visual system
- `script.js` — mobile navigation + small interaction
- `assets/` — reserved for optimized local assets

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Framework preset: Other / no framework.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Deploy.

## Important
The concept currently references selected images from La Sien's public website so the redesign can be evaluated quickly. For a production build, download/optimize approved brand assets into `assets/` and replace those URLs with local WebP/AVIF files.

The copy is based on publicly available information from La Sien's current website and should be reviewed/approved by the company before production use.

## Concept direction
The redesign intentionally moves the brand toward:
- stronger visual hierarchy
- premium blue/water palette
- large product imagery
- concise messaging
- mobile-first responsive behavior
- clearer product and distribution CTAs
- lighter page structure and fewer heavy visual dependencies
